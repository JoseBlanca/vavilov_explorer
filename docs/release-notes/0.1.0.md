Vavilov Explorer 0.1.0 is the first release of a desktop app for exploring
a table of individuals, such as accessions of a crop, in several linked
views: the individuals you select in the table are selected in every
plot, and those you put in a group take its colour everywhere. It is a
beta: it works, but it has had little use, and its windows may still
change. The tables it exports are ordinary CSV and Excel files.

## What it does

- **Imports** one table, a CSV, TSV or Excel file, with one row per
  individual and a first column headed `IndividualID`. The
  [user guide](https://github.com/JoseBlanca/vavilov_explorer/blob/main/docs/user-guide.md)
  says how to prepare it.
- **Shows the table**, where each cell can be edited, and each column has
  a role, chosen above its header: a number, a latitude, a longitude, a
  category, a country or text.
- **Groups individuals.** A category column is a classification and its
  values are groups. The groups panel adds, renames, recolours and deletes
  groups, and its + and − buttons move the individuals you select into a
  group or out of it. Edit > Undo takes back each change.
- **Finds rows** with the bar above the table, read as a sentence:
  "Find height ≥ 1,5", "Find origin is Peru", "Find note is missing".
- **Plots**, each in a window of its own, from the Plot menu:
  - a 3D scatter of three number columns;
  - a map of the individuals, by a latitude and a longitude column;
  - a map of the countries, coloured by how many individuals each holds;
  - a histogram of a number column, its bars stacked by group.

  In every plot you can select individuals with a click, or, in the 3D
  scatter and the map, by drawing a loop around them with the mouse, and
  put them in a group.
- **Exports** the table, with its groups, as CSV or Excel.

## What it does not do yet

- **It does not save a project.** When you quit, what is not in a file is
  lost. To keep your groups, export the table as CSV or Excel before
  quitting, and import that file next time: each classification is a
  column of the file.
- The histogram always cuts the values into 20 bars, and cannot yet be
  used from the keyboard, nor a run of bars selected by dragging.
- There are no bar plots yet.

## Installing it

Download the installer for your computer from the list of files below.
None of them is signed yet, which is why your system warns before opening
it.

- **macOS** (Apple and Intel chips): download the `.dmg`, open it, and
  drag Vavilov Explorer to Applications. The first time, macOS refuses to
  open it because it cannot check the developer. Open System Settings,
  then Privacy & Security, scroll down to the message about Vavilov
  Explorer, and choose Open Anyway.
- **Windows**: download the `.exe` and run it. Windows shows "Windows
  protected your PC": choose More info, then Run anyway.
- **Linux**: on Debian and Ubuntu, download the `.deb` and open it to
  install it. On other systems, download the `.AppImage`, a program in one
  file: allow it to run as a program in its Properties, then double-click
  it.

## Known problems

- The app has been used on macOS. It has hardly been used on Windows,
  and never on Linux: please report what does not work there.
- On the map of countries, a double click shows the whole world again,
  but first selects the country under the pointer, as a single click
  does. To show the whole world without it, move to the map with the
  Tab key and press Home.
- On the map of countries, the outline drawn around the map when you
  move to it with the Tab key is hard to see over coloured countries.
- On Linux, if the language set for the system's region is not
  installed, the windows may not open.

Please report problems, and what you would like next, on the project's
[issues page](https://github.com/JoseBlanca/vavilov_explorer/issues):
choose New issue and describe what you did and what you saw. It needs a
free GitHub account.
